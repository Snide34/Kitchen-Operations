# Kitchen Operations UI – Flutter Assignment

A pixel-perfect Flutter implementation of the Kitchen Operations UI based on the provided Figma design.

## 📌 Objective
This project was created as part of the Flutter Mobile UI Development Test.

The focus of the assignment is:
- Pixel-perfect UI implementation
- Reusable Flutter components
- Clean architecture
- Responsive mobile layout
- Proper spacing, typography, and theming
